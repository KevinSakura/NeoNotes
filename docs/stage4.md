# 第四阶段：完善60秒短曲、原演奏保留与歌词试唱

交付日期：2026-10-05。用户选择“先完善60秒短曲”，代码与隔离验收已完成。本阶段不启用全曲，没有发起新的真实模型请求；不将接口与模拟通过视为编曲效果或可唱性达标。

## 启动和体验

双击根目录 `启动工作台.cmd`，或在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_local.ps1
```

打开 http://127.0.0.1:8000。沿用 Conda `piano` 和现有前端依赖，不创建 `.venv`，不增加模型SDK，不重新下载SoundFont。正式前端为 `frontend/app`，后端为 `backend`；`frontend/prototype` 保留。

1. 在收集灵感页录制短片段，将“旋律参与方式”选为“完整保留原演奏，随后延展”。主题、音乐感觉、歌词选段仍按第三阶段规则输入。
2. 生成60秒候选。程序固定原演奏，模型负责窗口后的发展；页面显示保留数量和被过滤的模型音符数。候选需要明确采用。
3. 在候选的歌词展开区或保存与导出页点击“听这一句”，直接听该行的主旋律；也可只听整个歌词选段。字词随实际回放时间突出显示，随时可停止。
4. 亲自照词试唱，留意音域、跳进、字词停留和换气，再听完整编曲与实际渲染音频。在保存页查看当前版本的六类结构核对。
5. 保存手动修改后重新核对。只有结构符合并且人工完成旋律、四声部、曲风与试唱确认，才可记录审核通过。修改另存后不沿用旧审核。

试听不会自动勾选人工检查，也不识别人声。审核通过不会发起模型请求，全曲按钮继续禁用。

## 原演奏保留规则

第三阶段真实测试的失败来自候选未满足精确保留约束；没有保存原始失败响应，不能推断具体是哪类字段偏差。本阶段不再依赖模型逐音复制原始录制。

- 输入仍限30秒、160音符；每类乐器只允许一种Program/Bank。音域、同音重叠、歌词单旋律冲突和固定音色可用性在请求前检查，已知不可用输入不创建任务或付费请求。
- 原演奏的开始与结束按所选速度换算到480PPQ：分别四舍五入，极短音符至少1tick；不执行拍格量化、移调或力度修改。Program/Bank来自原输入，声部通道遵循GM鼓语义。声部音量仍来自编曲规划。
- 每个有参考的声部，锁定窗口为0到该声部原演奏的最后结束。窗口内只保留原演奏。模型音符起点早于锁定窗口结束的事件整条过滤，包括跨越边界的事件；过滤数量明确记录，不冒称模型精确复制成功。
- 最终键盘数组为“按开始秒排序的原演奏音符 + 窗口后模型事件（返回顺序）”。歌词 `note_indices` 索引这个完整数组。错误、重复、越界或缺失映射仍拒绝，不猜测模型意图或补漏词。
- 1200音符上限包含固定的原演奏。所有最终声部仍需满足完整60秒、段落参与、音乐内容与音色规则；保留输入不保证模型延展一定通过。
- 人工审核重新检查当前音符的实际秒位置、时长、音高、力度与Program/Bank，容许1tick舍入；参考窗口内额外音符也会拦截。改变原演奏约束后须重新生成。

原片段可能作为前奏，歌词也可映射到它；歌词与原旋律冲突不做静默修复。录制为多音时不能保留为单旋律歌词谱曲。自由改编仍需人工核对走向利用，本阶段没有引入音乐语义评分。

## 逐句试听与结构核对

逐句播放只包含该行字词实际引用的主旋律音符。通过完整速度图换算时间，直接移到行首，保留最多0.3秒准备和0.6秒尾音，不等待前面整段。临时独听主旋律，跳过其他声部与静音/独奏开关，保留原音色及音量；音量为零时明确提示。不会写入或改动混音设置。没有引用的前奏/间奏不加入试唱片段。

字词跟随音频线程的实际回放时间，一字多音在各音符期间显示，间隙没有活动字词。停止、切换页面/歌曲/候选、修改乐谱或保存新版本时结束旧回放。音符删除、映射重复、顺序或音域不合规时禁用歌词试听并提示原因。

保存页分别核对：60秒与四声部内容、共同段落与和声覆盖、所选字词及换气对应、原演奏约束、实际SoundFont预设、候选来源与原创作输入。失败给出具体原因；“重新核对当前版本”只执行本地检查。

含生成对应的歌曲在新保存时按当前音符更新MIDI歌词标记；移动音符后标记跟随实际起点。删除对应音符时不导出过期标记，JSON中的失败对应保留并阻止审核，不猜测替代音符或漏词成功。旧版本及旧导出文件不改写。外部MIDI没有composition资料时保持原有元信息处理。

逐行展示时间范围、字词/音符数、实际音域、最大相邻跳进及句前间隔；跨越一个八度或跳进超过7半音时提示人工留意。这些阈值只是试唱提醒，不能代表歌手能力、安全音域、音乐评分或已经可唱。英文多音节、中文声调/重音及表达仍需人工判断。
