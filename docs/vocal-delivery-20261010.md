## 启动与使用

本机资源和工具已准备好，双击根目录 `启动工作台.cmd`，访问 **http://127.0.0.1:8000**。也可在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_local.ps1
```

选择已有的全文歌词作品，保存后进入 **保存与导出 → 让歌手唱出这首歌 → 生成演唱 / 更新合听**。首次发音错误可展开“修正读错的字”，选原行/字，填写 `chong`、`zhe` 等无声调拼音，ü 写作 `v`；应用并重新生成。修改只保存演唱设置，不改汉字和原谱。读音及资源有错误时显示原因，原作品保留。

音量滑块即时改变试听；新下载文件要点击“生成演唱 / 更新合听”保存。人声伴奏采用完整声部并保留保存音量，忽略静音/独奏，仅按绑定集合删除导唱。器乐面板仍负责原先按静音/独奏的混音。人声/伴奏 WAV 同时起播；浏览器压缩器与导出限幅/声道转换有电平差异，发布前还应试听下载的混音。

新机器或资源缺失时，执行官方资源准备与宿主构建，不在启动时自动下载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup_vocals.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_vocal_worker.ps1
```

前一步联网下载固定版本并检查摘要；后一步使用项目内 SDK 和无外部包的恢复配置编译，再检查设备、生成资源清单。所有 Python 命令继续 `conda run -n piano`。本机资源正常时无需再执行准备脚本；发现资源校验失败时不要手改资源清单掩盖错误。

启动脚本也执行 `scripts/check_vocal_resources.py` 的只读资源检查。单独排查可运行 `conda run -n piano python scripts/check_vocal_resources.py`；不读取模型配置或请求 API。资源不可用时返回失败，工作台仍可启动进行歌曲编辑。

## 数据与实现边界

```text
data/<song_id>/
  revisions/<revision_id>.json            原输入与原谱，演唱不改写
  vocal-settings/<settings_hash>.json     不可变歌手/读音/音量/设备设置
  vocal-settings/index.json               各保存版本当前设置指针
  exports/vocals/<job_id>/
    job.json                              状态、来源/模型/配置哈希、去掉的导唱ID、文件指标
    input.json                            保存版本和完整演唱转换快照
    singing.ustx                          实际 OpenUtau 演唱工程
    accompaniment.mid                    派生伴奏，原MIDI不覆盖
    vocal.wav                            单声道44.1kHz PCM16干声
    accompaniment.wav                    双声道44.1kHz PCM16伴奏
    mix.wav / mix.mp3                     双声道合听；MP3为192kbps
    worker-report.json                    音符/音素/句位置、padding及耗时
    work/                                工具日志、请求、逐句原始WAV及缓存
data/.trash/<song_id>/                    整首恢复，原ID和上述文件一起恢复
```

三类 WAV 均从歌曲0秒开始，帧数为 `round((乐谱秒数+3)*44100)`，末50ms淡出。宿主按 OpenUtau 的 `positionMs-leadingMs` 放回每句的绝对位置，保留无词空白，不把句子依次拼接或裁掉非发声开头。每句原始输出和偏移保留在 work 中。MP3 有编码延迟，不作为两轨同步基准。完成文件先校验再标记成功；未完成文件不提供下载。

限制与风险：

- 初版只接受普通话汉字，含英文、数字的字词先明确读法并修正歌词与对应；不猜测替词。旧选段没有全文对应时明确拒绝。
- 一字多音需要相邻连续的绑定音符；跨休止/无词器乐音符的续唱、缺失/重用/错序对应会拒绝。小节中途的拍号变化暂不支持。0秒起音若不能容纳辅音提前量，明确失败，不静默挪动人声或改原谱。
- 不预测或重写原旋律。上游默认短滑音、音素提前量会影响瞬时 F0/听感；不承诺所有原谱音域都适合绮萱。音准、中文重音和舒适性需要听验。
- 宿主初始化使用固定版本核心的调度/路径适配，其中含私有路径 setter；上游不是稳定插件 SDK。beta 版本、驱动与 ONNX 兼容性是后续维护风险。
- 音频子工具单次120秒、完整宿主1800秒超时，超时/取消停止拥有的子进程；没有自动重试。一次仅一个演唱推理任务，不承诺实时演唱。
- 取消试听也中止正在加载的两轨。人声接口在锁内完成有上限的文件读取并关闭文件，再发送 HTTP，避免 Windows 下载/试听流占用阻止歌曲移动。单个响应最多110MiB；长曲同时加载会占用额外内存，初版针对本地单用户。
- work 保留原始句文件和缓存，回收站不释放空间。请备份整首歌曲目录，当前没有自动历史/缓存永久清理。
