# NeoNote 本地基础单元交付

日期：2026-10-14。用户授权在已有练习模块加入面向新手的本地固定谱。本轮保留MIDI导入、歌曲复制、键位、两轮规则与历史；无新增依赖、模型/付费请求、歌声推理、歌声资源下载或真实.env访问。开发测试只用隔离目录。

## 启动与实际流程

停止旧服务，重新双击根目录 `启动工作台.cmd`，打开 `http://127.0.0.1:8000`，点击顶部“练习”。开发方式继续使用 `scripts/start_dev.ps1`，Python仍为Conda piano。更新后重新构建正式前端即可，无需重新安装依赖或准备歌词/模型配置。

1. 在“本地基础单元”选择单元，点击某条“查看练习谱”。首次打开练习页面不自动创建15份材料；只有明确选择一条时才准备其本地副本。
2. 查看五线谱和按键/演奏提示，点击“确认五线谱并保存练习版本”。固定谱已经确定轨道、音高和时值，无需选轨、量化或先创作。
3. 点击“开始新的认音轮”，等待本地SoundFont就绪后演奏。按错可纠正，和弦仍需同一次答案中同时构成；首次答案不会清零。
4. 全部目标最终正确后，明确点击“从头开始节奏轮”，继续使用预备拍、0.5/0.75/1倍、暂停续练、音高/起音/漏音/休止及时值提示。
5. 单元卡片在保存后更新认音与节奏记录。再次选择相同练习复用已保存谱版本，但“开始新的认音轮”建立新会话，不重置以前的成绩；记录页可按单元/练习名称查看、恢复及下载JSON。

“选择练习材料”仍提供原MIDI导入、已有材料及从保存歌曲复制入口。固定教材不是原验收目录中的测试样本，不依赖.cache；即使没有任何歌曲或自选材料，基础单元也可读取并使用。

## 5个单元、15条原创固定谱

全部为高音谱表、4/4、72BPM、2–4小节，默认4档可演奏C4–C5，不要求Shift/空格换档。每条都有目标和具体键位/演奏提示，单元之间没有强制解锁。

| 单元 | 固定谱 | 目标 |
| --- | --- | --- |
| 单音认谱 | 认识C–G、走完一个八度、打乱顺序找音 | 先识音符位置，再找到白键。 |
| 黑键与升降号 | 认识C♯/D♯、另外三个黑键、换一种名字看黑键 | 覆盖五个黑键，包含降号及等音对应。 |
| 基础节奏 | 一拍与两拍、一拍中的两个音、休止时先不按 | 四分/二分/八分与休止，起音和松键分开。 |
| 简单旋律 | 上行下行、跳过一个音、同音再敲一次 | 级进、跳进、独立重复起音与长音。 |
| 和弦与延音 | 两个音一起、两个三和弦、跨小节保持 | 双音、C/F三和弦、一个来源音跨小节一次起音。 |

谱面由项目原创定义，不复制第三方作品、教本或测试曲，不通过AI临时生成。固定谱通过结构/键位检查不等于教学效果或实体听感达标；这些材料是入门练习，不是完整专业课程。

## 实现、保存与版本

教材源码在 `backend/resources/practice-units-v1.json`。`backend/app/practice_units.py`校验目录、唯一ID、音域、正时值与完整小节，确定性生成MIDI，复用独立解析/记谱/目标编译；程序创建实际音符ID和延音目标。编译检查不量化、不删音，不调用创作导入接口。

`GET /api/practice/units`只读提供目录，不创建数据。`POST /api/practice/units/<练习ID>/prepare`校验并准备独立副本与预览，仍由用户明确确认版本和开始会话。按存储锁复用相同教材/编译内容的副本，重复或并发选择不重复导入。缓存损坏、资源缺失/不合法或未知练习返回具体错误，不用替代或随机谱掩盖失败。

继续保存到 `data/.practice/materials/<材料ID>/` 和 `data/.practice/sessions/<会话ID>/`。source.mid、解析材料、settings/notation/targets/MusicXML、不可变revision与逐批事件沿用原合同；在source/revision/session追加可选builtin身份：目录与单元ID、练习名称、教材定义及实际MIDI/默认设置/记谱/目标/XML哈希。旧导入材料与旧会话按原逻辑读取，不补写builtin标记。

只有默认设置和实际谱/目标都与固定教材一致的保存版本才标标准单元。通过接口对副本移调或改整理参数的版本可以练，但不计入原固定谱的进度。教材或编译内容变化会得到新身份、副本与版本，旧记录保留，不静默替换或继承成绩。

前端单元状态来源于后端保存记录，并只匹配同一练习的当前artifact_hash。认音全部最终正确为“认音已完成”；从谱头到曲末的一次完整节奏段为“完整节奏轮已练”；该完整段达到原有建议标准才另外标“达到建议标准”。仅从后半段恢复到曲末不会算完整节奏轮，不把多个暂停段拼成一次成绩。首次组准确率与音高准确率仍按原规则保留，学习进度不改变评分容差、时钟或人工验收状态。

## 人工检查与剩余范围

| 检查目标 | 启动/操作 | 达成标准 |
| --- | --- | --- |
| 空项目入门 | 启动后直接进练习，选择“认识C–G”，不上传MIDI或建歌 | 显示对应五线谱与提示，确认后能认音和开始节奏，操作说明能理解。 |
| 首次与纠正 | 第一音错按j再改s，完成其余d/f/g/h/f/d/s；刷新恢复记录 | 首次完整正确组比例87.5%，9次尝试保留；最终全对解锁，首次错误不消失。 |
| 黑键与记谱 | 选择三个黑键练习，核对升/降号，按提示e/r/y/u/i | 谱面音高和发声一致，降号对应同一黑键，不被音名文字误导。 |
| 和弦、时值与延音 | 多键自检后练双音/三和弦；长音跨小节保持，独立同音松开重敲 | 和弦没有漏键或残音；延音只起一次，休止不新起音；设备无法完成时使用替代操作或标记问题。 |
| 保存与单元选择 | 暂停后改选其他谱，再重开/刷新；保留旧练习并查看记录 | 每条谱与会话各自保存，重复选择不增副本；只有完整节奏段计“已练”，达到标准另标；旧谱/旧尝试不会丢失。 |
| 教学节奏与设备 | 用有线耳机从0.5倍练起，试原速及敲拍估计 | 难度适合新手，提示清楚，音符位置和按键易对应；真实设备延迟/听感与多键冲突另记，不由自动测试代替。 |

本轮不提供自动出题、自适应难度、外接MIDI、完整乐理课程、教材编辑器或新的进度通关门槛。所有单元可自由练习；真实键盘/设备延迟、主观听感、教学效果与长会话性能仍待人工核验。
