# 独立 HTML 页面原型（历史名称：拾音）

正式项目于2026-10-09更名为 **NeoNote（新的乐章）**。本页记录早期原型，`frontend/prototype` 文件及其 `localStorage` 存储键保持原样，正式工作台使用新名称。

日期：2026-10-04。用途是体验页面、讨论交互和调整功能，不作为正式产品。无第三方前端依赖、无 CDN、无 API 调用、不读取 `.env`。

## 信息架构

| 位置 | 内容与操作 |
| --- | --- |
| 左侧歌曲区 | 新建演示歌曲、切换歌曲；输入、音符和历史相互独立。初始歌曲内含明确标示的预设编曲。 |
| 顶部 | 当前歌曲、浏览器保存状态、操作历史。 |
| 01 收集灵感 | 四种合成音示意、鼠标/电脑键盘试弹、录制/回放、旋律模式、歌词全文/连续选段、主题/情感、模拟生成状态。 |
| 02 编曲与调整 | 四声部选择、独奏/静音、音色/音量、示例钢琴卷帘、音符增删及表单移动/改时长、撤销重做、整曲修改演示。 |
| 03 审核与导出 | 当前版本检查清单、明确人工审核、后续全曲说明、MIDI/MP3 导出说明、下载原型 JSON。 |

采用浅色背景、绿色主操作、四声部颜色区分；先展示日常语言操作，额外生成设置折叠。桌面两栏，窄屏单栏。专业音符参数集中在编辑页，避免一开始要求用户理解乐理。

## 启动

最简单：用 Chrome/Edge 打开 `frontend/prototype/index.html`。`styles.css`、`app.js` 应与 HTML 放在一起。

推荐固定地址预览，在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_prototype.ps1
```

访问 http://127.0.0.1:8765 ，终端按 Ctrl+C 停止。使用 `conda run --no-capture-output -n piano python -m http.server` 提供静态文件；不启动 FastAPI，不依赖 requirements 安装结果。端口被占用时先停止之前的预览，避免在同一端口启动多个服务。

## 建议体验路径

1. 点击“开始录制”，按 A、S、D 等键，停止后回放；W、E、T、Y、U 对应黑键。文本框获得焦点时不会触发琴键。
2. 点击“试用示例歌词”或上传 UTF-8 TXT（最多 500 KB），勾选连续几行。勾选远处一行会补选中间行，取消某行会取消该行及之后的选段。
3. 填主题与情感，也可以不弹琴、只提供文字。试听音色、输入旋律模式只展示交互，不代表模型已接受约束。
4. 点击“体验生成流程”，看分阶段状态；在“更多创作设置”中可切换失败演示，也可以中途取消。成功只加载预设音符，失败/取消保留作品。
5. 在编曲页点击网格增加音符，选中后改音高、开始拍和时长，再应用；试试删除、撤销、重做，以及各声部控制。当前只编辑前 16 拍，无拖拽功能。
6. 输入任意整曲修改指令，按钮仅执行预设的“全部声部音符缩短 20%，最短 0.5 拍”，不解析文字意图。
7. 勾选审核项目并标记通过；修改编曲或输入后审核失效。全曲按钮只解释后续阶段，不触发生成。
8. 查看两种导出说明，或真实下载带 `prototype: true` 的 JSON。保存到浏览器后刷新，核对输入与音乐状态恢复。

## 真实交互与模拟范围

| 能力 | 实际行为 |
| --- | --- |
| 试弹、录制和回放 | Web Audio 振荡器发声，记录音高、起始、时长和选择的音色类别；并非 SoundFont 或真实乐器采样。失焦释放音符并停止录制/播放。 |
| 四声部播放 | 使用音符、音量、音色和静音/独奏设置发出合成音；前 4 小节循环至 60 秒。普通定时器用于此演示，不作为正式音乐调度实现。 |
| 歌词读取 | 浏览器读取本地 TXT 或接受粘贴；仅保存原文与选中行，没有歌词—音符对齐算法，无人声。 |
| 编曲编辑 | 改变浏览器内的预设音符，可撤销重做；撤销仅涵盖本次打开的编曲编辑，不涵盖输入材料。刷新后历史列表保留，撤销栈清空。 |
| 生成与自然语言修改 | 无模型连接，不依据主题/歌词/旋律生成音乐，不保证可唱性。成功、失败、取消为模拟状态。 |
| MIDI 导入 | 说明弹窗，不读取或解析 MIDI。 |
| MIDI / MP3 导出 | 说明弹窗，不产生虚假音乐文件；现有 FFmpeg / FluidSynth 不被调用。 |
| 工程保存 | 用户显式保存到 localStorage，键 `shiyin-html-prototype-v1`。不创建 data/歌曲目录，不依赖 SQLite。 |
| 原型 JSON 下载 | 实际下载当前歌曲状态与历史；用于设计讨论，尚无 JSON 导入。 |
| 人工审核 | 记录当前示例版本的通过状态；新编辑使其失效，不代表真实音乐验收。 |

浏览器存储按地址和浏览器隔离：file://、127.0.0.1、localhost、不同端口不保证共用；浏览器限制、隐私模式或清理缓存可能影响持久化。不要在原型中保存唯一副本，JSON 下载可留作讨论记录。正式工程仍按技术设计由后端存入 data/。

## 文件与后续修改位置

- `frontend/prototype/index.html`：文案、步骤、卡片与控件结构。
- `frontend/prototype/styles.css`：配色、间距、桌面与窄屏布局。
- `frontend/prototype/app.js`：示例数据、界面状态、浏览器保存和合成音逻辑。
- `scripts/start_prototype.ps1`：只提供原型目录的本地静态预览。
- `scripts/test_prototype.cjs`：无 npm 依赖的可选 Chrome 调试协议检查，需要 Node 22+、8765 预览与独立测试 Chrome 的 9229 调试端口；不应对个人浏览器会话运行，会清理测试地址的原型存储。

这些文件独立于后续 React 正式前端，HTML 原型不改变既定技术栈建议。
