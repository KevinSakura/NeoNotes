# NeoNote · 新的乐章 — Gemini 视觉重设计静态原型 (`frontend/front_gemini`)

本目录存放 **NeoNote（新的乐章）** 的全新前端视觉与交互重设计静态原型。设计围绕 **「日间暖调琴房（Warm Acoustic Atelier）」** 与 **「夜色母带录音棚（Midnight Mastering Console）」** 双主题展开，完整覆盖工作台总览、创作模式、识谱与节奏练习模式、乐曲键盘扒谱模式四大核心视图。

> **独立性与安全边界说明：**
> - 本目录为纯静态原型（`index.html` / `styles.css` / `app.js` / `README.md`），无任何外部 CDN 强依赖，可直接在浏览器双击打开。
> - **不连接本地后端**、**不读写 `data/` 正式目录**、**不读取或展示 `.env`**、**不发起 DeepSeek / 绮萱 DiffSinger / Transkun 真实推理请求**。
> - 未覆盖或修改 `frontend/app`（React 正式工作台）、`frontend/prototype` 或 `frontend/front_original`。

---

## 1. 启动与预览方式

### 方式一：直接双击打开（推荐）

在文件管理器中直接双击打开：

```text
frontend/front_gemini/index.html
```

### 方式二：通过本地静态 HTTP 服务预览

如果希望在本地端口下查看，可在项目根目录运行：

```powershell
conda run -n piano python -m http.server 8090 --directory frontend/front_gemini
```

随后在 Chrome 或 Edge 访问 `http://127.0.0.1:8090`。

## 2. 视觉设计理念与改进亮点

1. **双主题声学工坊美学（Warm Acoustic Atelier & Midnight Mastering Console）**
   - **默认日间暖调琴房（`data-theme="atelier"`）**：采用温润羊皮纸底色（`#F8F4EC`）、胡桃木深炭控制栏（`#24211E`）、赤陶朱砂主强调色（`#C85A32`）与松石绿状态色（`#286653`），降低长时间看谱与编辑音符的视觉疲劳。
   - **一键切换夜色录音棚（`data-theme="midnight"`）**：点击顶部横幅右侧按钮即可切换为黑曜石暗色面板与琥珀指示灯风格。
2. **拟物级 3D 电子键盘与实时电平反馈**
   - 象牙白键倒角与乌木黑键立体阴影，配合顶部实时跳动的 6 段式硬件电平表（OUT VU Meter），兼顾零基础新手的直观键位提示与专业乐器质感。
3. **四大视图全链路闭环呈现**
   - **00 工作台总览**：一屏了解三大独立入口与数据隔离承诺，右侧配备即刻试弹合成器琴台（支持钢琴、吉他、贝斯、GM 鼓组切换与和弦琶音示例）。
   - **01 创作工作台**：
     - 左侧歌曲工程栏（显示名与 `data/<歌曲ID>` 分离、新建歌曲、不可变历史版本 `v1–v4`、歌曲回收站 `data/.trash/` 整曲恢复）。
     - **Step 01 收集灵感**：支持 `A W S E D F T G Y H U J K` 键盘试弹与录制、Preserve（固定原演奏前缀）/ Extend（走向延展）选择、`lyric-motifs-v1` 全文歌词实时行数/字词计数（上限 64 行 / 1024 字词）与「本次不使用歌词」切换。
     - **Step 02 演奏与编辑**：四声部混音轨（Solo / Mute / 音量）、可点击选中与新增音符的 SVG 钢琴卷帘（Piano Roll）、逐句 `1.0× / 0.75×` 慢速循环练唱，以及「乐句与转音（v2 试验）」按字音符组原子编辑。
     - **Step 03 演唱、审核与导出**：绮萱 Qixuan v2.7.0 普通话独唱面板（含多音字如「行 xing/hang」无声调拼音修正）、人工试听与可唱性审核清单、3 分 15 秒无词整曲扩展入口，以及版本绑定的 MIDI / WAV / MP3（含 `+3秒尾音与50ms淡出` 说明）导出。
   - **02 识谱与节奏练习**：
     - 内置 5 单元 15 条原创短谱课程切换。
     - **严格遵循第 37 条布局规范**：桌面端在五线谱右侧并排展示常驻《练习按键说明》（窄屏自动移至五线谱下方），清晰列出白键 `s d f g h j k l`（`l` 恒为右侧高八度 C）、黑键 `e r y u i`、单按 `Shift / 空格` 切八度档位（3–5 档）、按住修饰键叠加八度副音规则。
     - 支持真实的电脑按键闯关：第一轮认音允许出错后原地纠正并同时保留首次准确率与纠正次数；全部正确后解锁第二轮节奏跟弹（含 4 拍预备拍与准拍偏移提示）。
   - **03 乐曲键盘扒谱**：
     - 选段波形可视化（最长 60 秒）、独奏直转与混音分离模式切换。
     - **混音分离试听确认门禁**（先载入分离钢琴试听，再明确点击继续转录）与 **选段边界求交诊断报告**（展示 `clipped_notes` 末尾截断音符数、`outside_notes` 补帧排除数，以及 `performance.mid` 与 `clip.mid` 独立下载）。
     - 音符级表格校对（MIDI 音高、起止秒数、力度、左右手分配）与支持 v2 动态 `voice_stride`（每手最多 32 声部）的高低音大谱表预览及 MusicXML 导出。

## 3. 模拟范围与正式迁移边界

- **当前已实现（静态原型内可交互）**：四大模式切换、日夜双主题切换、Web Audio 多音色实时发声与序列回放、创作与练习两套独立电脑键盘映射、录制与加入编曲、SVG 钢琴卷帘增删改音符与撤销重做、五线谱认音实时判题与首次准确率统计、扒谱音符表编辑与大谱表联动。
- **原型模拟范围**：页面中的歌曲工程列表、AI 候选编曲、绮萱演唱合成、FluidSynth 音频渲染及 Transkun/Demucs 扒谱结果均为前端内存示例数据，声音由浏览器内置 Web Audio 合成器实时模拟，不代表真实 GeneralUser GS SoundFont、DeepSeek 编曲或绮萱声库音质。
- **后续迁移边界**：若需将本套视觉设计迁移至 `frontend/app` React 正式工作台，需由用户另行确认迁移范围。
