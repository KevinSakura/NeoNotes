# NeoNote 前端视觉重设计原型（front_original）

这是 NeoNote 工作台的**视觉重设计原型**，用于在改动正式前端之前评估新的页面风格与布局。它是纯静态页面，不连接后端、不读写 `data/`、不调用模型，也不替换 `frontend/app` 或 `frontend/prototype`。

## 打开方式

直接用浏览器打开 `frontend/front_original/index.html` 即可，无需安装依赖或启动服务。可通过地址栏 `#home`、`#creation`、`#practice`、`#transcription` 直接进入对应页面。

## 设计方向

- **深色录音室风格**：深色背景搭配紫 / 青极光渐变、毛玻璃卡片与细描边，同时提供浅色主题（左下角「主题」切换，记忆在浏览器本地）。
- **统一导航**：左侧图标导航切换首页 / 创作 / 练习 / 扒谱；窄屏改为底部标签栏。
- **四声部固定配色**：键盘紫、鼓粉红、吉他橙、贝斯青，在卷帘、声部列表与候选预览中保持一致。
- **新手友好**：每个页面有一句引导标题；步骤条（收集灵感 → 演奏与编辑 → 保存与导出）显示进度；模拟、试验与待人工确认的状态都用标签明确标出。

## 页面内容

| 页面 | 原型展示 |
| --- | --- |
| 首页 | 品牌主视觉、三个入口卡片、最近作品 |
| 创作 · 收集灵感 | 歌曲列表 / 搜索 / 删除与回收站、四种音色切换、可弹奏的屏幕琴键（A–K 白键、W E T Y U 黑键）、录制与回放时间线、主题与音乐感觉标签、歌词计数（64 行 / 1024 字词）、AI 编曲同意确认与模拟候选 |
| 创作 · 演奏与编辑 | 播放控制、撤销、音符增删与移动 / 调整时长、静音 / 独奏 / 音量、四声部卷帘、整曲自然语言修改、人工审核清单、逐句练唱（0.75× 只影响试听） |
| 创作 · 保存与导出 | 工程信息、历史版本时间线、MIDI / WAV / MP3 导出卡片、现成歌手演唱与合听音量 |
| 练习 | 5 个本地单元卡片、SVG 五线谱、认音判定与纠正记录、节奏轮预备拍与偏差显示、按键提醒与基础八度指示（s–l 白键、e r y u i 黑键，Shift / 空格单按切档） |
| 扒谱 | 任务列表、拖放上传、波形与 60 秒选段、钢琴独奏 / 混音分离（试验，需试听后继续）、四步流水线进度、结果预览与导出按钮 |

## 模拟范围

- 声音使用浏览器振荡器生成的**简易合成音**，不代表 GeneralUser GS 音色或渲染效果。
- 歌曲、历史、AI 候选、扒谱结果均为**示例数据**；保存、导出、生成、上传等按钮只演示交互状态。
- 练习页只实现单音判定、按住修饰键的双音和单按切档的简化演示，完整组合规则以正式应用为准；节奏 ±120 ms 为演示阈值。
- 原型视觉确认后，再将样式迁移到 `frontend/app`；迁移需另行确认范围。
